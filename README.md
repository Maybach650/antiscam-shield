# 🛡️ AI Anti-Scam Shield

AI-powered scam call detector for Turkmen and Russian languages.

## Features
- Detects scam phone calls using Machine Learning
- Supports Turkmen and Russian languages
- 96.6% accuracy
- Web interface built with Flask
- Audio transcription with Whisper (coming soon)

## Scam Types Detected
- Fake bank calls
- Fake police calls
- Fake lottery calls
- Fake relative in trouble

## Tech Stack
- Python
- Scikit-learn (TF-IDF + Logistic Regression)
- Flask
- Faster-Whisper

## How to Run
```bash
pip install -r requirements.txt
python app.py
```
Open http://localhost:5000
